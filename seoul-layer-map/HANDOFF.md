# 인수인계: 지대(공시지가) 레이어 얹기

2026년 11월 26일 기준으로, 이 지도를 이어 작업할 다음 대화에 넘기는 메모입니다. 새 작업은 이 문서와 `README.md`를 먼저 읽고 시작하면 됩니다.

## 지금 상태

- 공개 주소는 <https://rosewein.github.io/seoul-layer-map/>이고, 원본은 이 저장소(`rosewein/rosewein.github.com`)의 `seoul-layer-map/` 폴더입니다. master에 올리면 GitHub Pages에 몇 분 안에 반영됩니다.
- 레이어는 시역·구 경계(1914–), 전차·기동차(1899–1968), 철도, 지하철·광역철도(1974–), 버스 노선망(1998–2026), 마을버스(2015–, 정류장과 마을버스로만 닿는 땅), 연표입니다.
- 지도는 D3 v7.8.5와 topojson 3.0.2(cdnjs)를 쓰고, 데이터가 모두 들어간 HTML 한 파일입니다.
- 만든 사람(이지)은 지리학 전공(인문·도시)이고, 개인 연구로 하고 있습니다. 설명은 한국어, 사실은 출처를 확인해 가며 쓰고, 확인한 것·추정·확인 못 한 것을 나눠 밝히기를 원합니다.

## 다음에 하고 싶은 것

1. 서울 땅값을 시대별로 강수량 지도처럼 색으로 칠한 레이어
2. 지하철역 개통 전후로 역 주변 땅값이 서울 전체보다 얼마나 더 올랐는지 보기(개통 연도는 `data/metro.json`에 역마다 있음)
3. 버스·지하철이 많이 다니는 곳에서 땅값이 되먹임으로 더 오르는지(이지는 이걸 "지대 증폭"이라고 불렀습니다. 정해진 용어는 아니고, 가까운 개념은 알론소의 입찰지대 이론과 뮈르달의 누적적 인과입니다)

## 자료 후보

- 서울 열린데이터광장 「서울시 개별공시지가 정보」(OA-1180)를 쓰면 됩니다. 데이터셋 페이지 파일 탭에 1990–2026년 연도별 zip이 있고, 이용허락범위는 "제한 없음"으로 표기되어 있습니다. 1990년대 파일의 항목 구성(필지 고유번호 PNU가 있는지)은 아직 확인하지 않았습니다.
- 공시지가 제도는 1989년 말 첫 표준지 고시로 시작했습니다(서울신문 1990.5.2 「건설부, 전국 30만곳 공시지가 고시」). 그 전 시기는 체계적인 자료가 없습니다.
- 파일 내려받기는 작업 공간에서 막혀 있으므로, 이지가 브라우저에서 받아 주면 연결된 컴퓨터에서 옮겨 오는 방식이 됩니다. 지난번엔 크롬에서 받은 파일이 다운로드 폴더에 `.tmp`로 남아도 크기가 맞으면 그대로 옮겨 쓸 수 있었습니다.

## 그리기 제안(지난 대화에서 이지와 이야기한 것)

- **공간 단위:** 처음엔 법정동입니다. 법정동 경계는 `data/emd_topo.json`(TopoJSON, 객체 `seoul_neighborhoods_geo`, 467개, 속성 `cd` 8자리 법정동 코드·`nm` 동 이름·`gu` 구 코드)에 이미 있어서, 공시지가 파일의 법정동 코드로 묶기만 하면 됩니다. 필지 단위는 연속지적도 도형이 따로 필요하고 용량이 큽니다.
- **값:** 그 해 서울 전체 중앙값의 몇 배인지(상대값)로 칠합니다. 물가와 제도 변화 때문에 원값으로는 시대 비교가 안 됩니다.
- **색:** 로그 눈금이 필요합니다. 명동(2026년 ㎡당 1억 8,840만 원)과 외곽은 수백 배 차이가 납니다.
- **해석할 때:** ㎡당 최고치는 명동처럼 보행 상권의 작은 1층 필지에서 나오므로, 노선이 촘촘한 환승역과 순위가 꼭 같지는 않을 것으로 추정했습니다(확인 전).

## 코드 구조

- `src/template.html`은 지도 틀입니다. `/*__DATA__*/` 자리에 `build.py`가 `const DATA = {...}`를 넣습니다. 결과는 `seoul-tram-boundary.html`이고, `make_publish.py`가 그걸 완전한 문서(`index.html`)로 감싸 공개용 폴더로 복사합니다.
- 그리기 그룹 순서는 `gArea, gNew, gRings, gDong, gGu, gRiver, gWall, gTram, gRail, gMetro, gBus, gLabels, gHit`(template.html 230행 근처)입니다. 땅값 레이어는 면이므로 `gArea` 다음, 경계선 아래에 새 그룹을 두는 게 자연스럽습니다.
- 레이어 켜고 끄기는 `.chip[data-layer]` 단추와 `layerOn` 객체(284행 근처), 연도마다 다시 그리는 곳은 `render()`(340행 근처)입니다. 위쪽 판의 수치 한 줄은 `#statLabel`, 아래 설명문은 `src/method.html`(DATA.methodHtml)입니다.
- 색 토큰은 `:root`의 CSS 변수이고, 어두운 화면용 값이 따로 있습니다. 새 색을 넣을 때 두 곳 모두 정의해야 합니다.

## 데이터 파일 요점

- `metro.json`: `lines`(선로 형상), `stations`(역마다 `opens` 노선별 개통 연도, `dates`, `first`)
- `bus.json`: 2004년 6월 노선망. `routes`(oy·cy·live), `segs`(같은 노선 집합이 지나는 구간 묶음, `r` = 노선 번호 목록), `events`, `stats`(공식 노선 수·대수)
- `bus2026.json`: 2004년 이후 노선망. `nums`가 노선 단위이고, 지금 노선은 `oy`(운행 시작 연도, 정수), 없어진 노선은 `dead: 1`과 `oy`·`cy`(연 + 월 소수)가 있습니다. 없어진 노선은 그 해 7월 1일에 다녔으면 그립니다.
- `route_years.json`: 2026년 노선마다 운행 시작 연도와 근거(개편/계승/신설/미확인). "계승"은 지난 대화에서 붙인 이름이고, 개편 노선이 통합·번호변경·형간전환으로 이어진 것을 뜻합니다.
- `dead_routes.json`: 2004년 7월 이후 없어진 노선 219개의 경로와 운행 기간
- `village_layer.json`: 해마다(2015–2022, 2026) 마을버스 정류장 좌표와 "마을버스로만 닿는 땅" 다각형. `village.py`(승하차 파일 → 정류장·300m 범위) → `village_clip.py`(서울 경계로 자르기)로 만듦. 2023–2025년 파일은 아직 안 받음
