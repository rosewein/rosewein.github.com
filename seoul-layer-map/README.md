# 서울 도시 연대지도

1899년 경인선과 전차부터 지하철·철도·버스, 1990년 이후 땅값(공시지가)과 1960년 이후 새 건물까지, 서울의 교통망과 시역·행정구역, 땅값과 건물이 바뀌어 온 과정을 연도별 레이어로 겹쳐 보는 지도입니다. 개인 연구로 만들었습니다.

**지도 보기: <https://rosewein.github.io/seoul-layer-map/>**

연도 띠를 움직이거나 재생 단추(0.5×·1×·2×·4×)를 누르면 해마다 바뀐 모습이 나옵니다. 그 해에 일어난 일은 연도 아래에 작게 뜨고, 지도를 확대하면 역 이름이 나옵니다. 선이나 땅, 정류장을 누르면 개통일·편입 연도·지나는 노선이 나옵니다. 화면 위쪽 탭으로 지도·연표·표와 자료·땅값과 건물·읽는 법을 오가고, 연표에서 시기나 항목, 10년 단위를 누르면 그 해 지도로 돌아갑니다. 주소 끝에 연도를 붙이면(예: `#1965`) 그 해가 바로 열립니다. 자세한 작성 방법과 한계는 「읽는 법」 탭에 적어 두었습니다.

## 버스 노선망을 맞춘 방법

- **1998–2003년**은 2004년 7월 대개편 직전(2004년 6월) 노선망에서, 그 뒤에 생긴 노선을 빼고 그 사이 없어진 노선을 더해 거꾸로 맞췄습니다.
- **2004–2026년**은 2026년 11월 노선망(서울 열린데이터광장 승하차 자료의 정류장 순번)에서 노선마다 "언제부터 그 길에 버스가 다녔나"를 정해 그 해 뒤에 생긴 노선을 뺐습니다. 여기에 2004년 7월 이후 없어진 노선 219개를 나무위키 폐선 문서에서 되살려 더했습니다.
- 경유지와 정류장 사이는 OpenStreetMap 도로망의 최단 경로로 이었습니다. 실제로 다니던 길과 다를 수 있습니다.
- 이렇게 맞춘 해마다의 노선 수는 공식 집계와 몇 % 안에서 맞습니다(2004년 439개 / 공식 457개, 2010년 373 / 369, 2020년 368 / 375).

## 저장소 구성

이어서 작업할 때는 [HANDOFF.md](HANDOFF.md)(인수인계 메모)를 먼저 읽어 주세요.


```
seoul-layer-map/
├─ index.html   지도(데이터가 들어 있는 한 파일)
├─ data/        index.html에 들어간 가공 데이터(JSON)
├─ fonts/       페이지에 쓰는 글자만 담은 글꼴(woff2)과 라이선스 원문. build.py가 만듦
└─ src/         가공·빌드 스크립트(Python)와 지도 틀(template.html), 설명문(method.html)
```

## 다시 만들기

지도만 다시 만들 때는 저장소를 받은 뒤 `python3 seoul-layer-map/src/build.py` 한 번이면 됩니다. `src/`의 틀과 `data/`의 자료를 읽어 `seoul-layer-map/index.html`을 씁니다.

글꼴은 `src/fonts.py`가 빌드 때 페이지에 든 글자를 모아 `fonts/`에 만듭니다. 글자 모음이 지난번과 같으면(`fonts/manifest.json`) 그대로 두고, 바뀌었으면 원본 TTF를 google/fonts의 고정된 커밋에서 받아(`$SLM_RAW/fonts`, sha256으로 확인) 다시 만듭니다. 이때 `pip install fonttools brotli`가 필요합니다. 새로 만들지 못하면 있던 파일을 그대로 쓰고, 빠지는 글자 수를 알려 줍니다.

자료를 처음부터 다시 만드는 스크립트는 원자료(BBBike 서울 OSM 추출본, 열린데이터광장 CSV, 나무위키 문서 모음)가 있어야 돌아갑니다. 원자료는 크기와 이용 조건 때문에 넣지 않았고, 놓인 곳은 환경변수 `SLM_RAW`로 알려 줍니다(경로는 `src/paths.py` 한곳에 모여 있음). 대략의 순서는 다음과 같습니다.

1. `roads.py` — OSM 추출본에서 도로망 그래프 만들기
2. `bus_parse.py` → `bus_build.py` → `bus_route.py` — 2004년 6월 노선망
3. `bus2026.py` — 2026년 노선망(첫 번째 실행)
4. `route_years.py` — 2026년 노선별 운행 시작 연도
5. `bus_dead_parse.py` → `bus_dead_route.py` — 2004년 이후 폐선 노선 복원
6. `bus2026.py` — 폐선 노선을 넣어 다시 실행
7. `water.py` — OSM 추출본에서 물길(한강 수면 면, 이름 있는 하천 선) `water.json` 만들기
8. `landprice.py <zip 폴더>` — 개별공시지가 연도별 zip(37개)에서 법정동별 중앙값 `landprice.json` 만들기
9. `building.py <csv 폴더>` — 건축물대장 표제부와 폐쇄말소대장 표제부 CSV에서 법정동·사용승인 연도별 연면적 `building.json` 만들기(보고서 `building_report.json`은 `$SLM_RAW/build`에)
10. `build.py` — `template.html`에 데이터를 넣어 `index.html` 만들기(`make_publish.py`의 `wrap()`으로 완전한 문서로 감쌈)

## 한계

- 새 건물은 지금 건축물대장에 폐쇄말소대장의 '말소'를 더했지만, 말소일이 적힌 줄의 99.5%가 2000년 이후라 그 전에 헐린 건물은 거의 빠져 있습니다. 1960~80년대 값은 실제보다 작은 하한값입니다. 사용승인일이 빈 건물(지금 대장 5.4%, 말소대장 9%)과 법정동이 빈 은평구 줄(약 3,200줄)도 빠집니다.
- 땅값은 시세가 아니라 공시지가(행정 평가값)이고, 파일에 면적이 없어 법정동 중앙값은 필지 수 기준입니다. 2006년 파일에는 필지가 앞뒤 해의 3분의 2 정도만 실려 있어 그 해 값은 덜 정확합니다.
- 노선 선형은 지금(2026년 11월) 도로망 위의 최단 경로라서, 그때 없던 도로를 지나가게 그려질 수 있습니다.
- 2026년 노선은 모두 2026년 경로로 그렸습니다. 그 사이 바뀐 경로는 반영하지 않았습니다.
- 1998–2003년 버스 노선망은 경로를 아는 노선만 그려서 공식 집계보다 적습니다.
- 노선 연도와 폐선 노선 자료의 상당 부분은 나무위키 본문에서 자동으로 뽑은 것이라 틀린 곳이 있을 수 있습니다. 지도에서 근거가 약한 사건에는 "자동 추출, 확인 필요"를 붙였습니다.
