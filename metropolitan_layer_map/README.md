# 수도권 도시 연대지도

1899–2026년 서울·인천·경기의 행정구역 경계와 철도·전철, 신도시·택지 지구, 고속도로·자동차전용도로, 조선 후기 대로, 광역버스·시외버스를 연도별 레이어로 겹쳐 보는 지도다. 「서울 도시 연대지도」(`../seoul-layer-map/`)를 수도권으로 넓힌 이지의 개인 연구이고, 아직 시안이다.

- 상태: 작업 브랜치 `metropolitan-layer-map`에만 있다. 이지가 화면을 더 확인한 뒤 master에 합치면 <https://rosewein.github.io/metropolitan_layer_map/>로 공개된다.
- 처음 만든 곳: claude.ai 아티팩트 「수도권 도시 연대지도 시안」(2026-11-26–27, 열여덟 번째 판까지). 이 폴더의 `index.html`·`data.json`은 그 판과 같다.
- 이어서 작업하는 법은 `HANDOFF.md`, 레이어별로 정한 것과 근거는 `docs/구상.md`(경계·철도·바다·강·신도시·도로·조선 후기 대로)와 `docs/버스.md`(광역버스·시외버스·터미널)에 있다.

## 폴더

- `index.html`, `data.json`: 지도(d3 7.8.5를 cdnjs에서 읽음).
- `src/sudo/`, `src/sudo2/`: 자료를 만드는 스크립트와 사람이 정한 작은 자료(노선 연도 결정 `bus/namu/decide_68.py`, 시외버스 노선표 `bus/siwoe/siwoe_entries.json`, 터미널 표 `bus/siwoe/terminals.py` 등). 스크립트는 처음 작업 공간의 절대 경로를 그대로 쓴다(`HANDOFF.md` 「새 작업 공간에서 시작하는 법」).
- `src/setup_workdirs.sh`, `src/collect_back.sh`: 작업 경로로 복사하기, 작업 경로에서 되가져오기.
- `docs/`: 레이어별 기록(claude.ai 프로젝트 「서울 도시 연대지도」의 문서 「수도권 연대지도 구상」「수도권 연대지도 버스」를 2026-11-27에 옮긴 것).

- 시안 1–12판(2026-11-26): 경계 1899–2026, 국철·전철, 38선, 바다·이웃 땅·강, 신도시·택지 지구, 고속도로, 자동차전용도로, 조선 후기 대로.
