# 수도권 도시 연대지도

1899–2026년 서울·인천·경기의 행정구역 경계와 철도·전철, 신도시·택지 지구, 고속도로·자동차전용도로, 조선 후기 대로, 광역버스·시외버스를 연도별 레이어로 겹쳐 보는 지도다. 「서울 도시 연대지도」(`../seoul-layer-map/`)를 수도권으로 넓힌 이지의 개인 연구다.

- 주소: <https://rosewein.github.io/metropolitan_layer_map/>. 고치는 일은 작업 브랜치 `metropolitan-layer-map`에서 하고, 이지가 화면을 확인한 뒤 master에 합친다.
- 처음 만든 곳: claude.ai 아티팩트(2026-11-26–27, 열여덟 번째 판까지). 그 마지막 판을 저장소로 옮겨 이름과 설명문을 다듬은 것이 v1.0이다.
- 이어서 작업하는 법은 `HANDOFF.md`, 레이어별로 정한 것과 근거는 `docs/구상.md`(경계·철도·바다·강·신도시·도로·조선 후기 대로)와 `docs/버스.md`(광역버스·시외버스·터미널)에 있다.

## 폴더

- `index.html`, `data.json`: 지도(d3 7.8.5를 cdnjs에서 읽음). v1.1부터 탭 셋(지도 / 읽는 법 / 자료 범위·출처)으로 나뉜다.
- `src/sudo/`, `src/sudo2/`: 자료를 만드는 스크립트와 사람이 정한 작은 자료(노선 연도 결정 `bus/namu/decide_68.py`, 시외버스 노선표 `bus/siwoe/siwoe_entries.json`, 터미널 표 `bus/siwoe/terminals.py` 등). 스크립트는 처음 작업 공간의 절대 경로를 그대로 쓴다(`HANDOFF.md` 「새 작업 공간에서 시작하는 법」).
- `src/setup_workdirs.sh`, `src/collect_back.sh`: 작업 경로로 복사하기, 작업 경로에서 되가져오기.
- `docs/`: 레이어별 기록(claude.ai 프로젝트 「서울 도시 연대지도」의 문서 「수도권 연대지도 구상」「수도권 연대지도 버스」를 2026-11-27에 옮긴 것).

## 변경 기록

지도 아래 작은 글씨에 지금 버전이 나온다. 공개한 판을 v1.0으로 하고, 레이어를 더하거나 화면이 크게 바뀌면 둘째 자리(v1.0 → v1.1), 화면·기술만 고치면 셋째 자리(v1.0 → v1.0.1)를 올린다. 「서울 도시 연대지도」와 같은 규칙이다(2026-11-27 이지가 정함). 버전마다 그 내용이 들어간 커밋을 적어 둔다.

| 버전 | 날짜 | 커밋 | 바뀐 점 |
|---|---|---|---|
| v1.1 | 2026-11-27 | (적을 예정) | 화면을 탭 셋(지도 / 읽는 법 / 자료 범위·출처)으로 나눔. 지도 탭은 화면을 채우고, 레이어 단추와 범례는 지도 오른쪽 판으로 옮김(폭 900px 이하는 지도 아래). 첫 문단과 지도 아래 설명문은 「읽는 법」 탭에 주제별로 묶음. 국철 전체를 철도 기호(선 위 짧은 가로 눈금)로 그림. 경부선 영등포 남쪽의 HGIS 미완성 선형(가는 점선)을 지금 선로 모양(metroscope·OSM)으로 바꿔 1905년부터 실선으로 그림 |
| v1.0 | 2026-11-27 | `9549462` | 첫 공개. 이름을 「수도권 도시 연대지도」로 하고 탭 제목·머리글·첫 문단·연천군 보정 메모에서 「시안」을 뺌. 첫 문단에 조선 후기 대로·광역버스·시외버스·터미널까지 넣고, 끊겨 있던 보정 문장과 광역버스 문장을 채움. 지도 아래 출처 문단에 1899–1910 보정, 시화 간석지, 시외버스 지명 자리·경로의 출처를 더하고, 적용 범위 표의 터미널 줄에 터미널 자리를 어림했다는 것을 적음. 시외버스 터미널의 방면 화살표를 빼고 점만 남김(방면과 행선지는 점을 누르면 나오는 정보창에). 누른 점은 크게 보이고, 전철 선이 위로 지나가는 점도 누를 수 있게 함 |

공개 전에 claude.ai 아티팩트에서 고친 판:

- 1–12판(2026-11-26): 경계 1899–2026, 국철·전철, 38선, 바다·이웃 땅·강, 신도시·택지 지구, 고속도로, 자동차전용도로, 조선 후기 대로.
- 13–16판(2026-11-27): 광역버스 — 경기 299개에서 인천·서울 면허와 없어진 노선, 2004년 개편 전 서울 좌석버스를 더해 359개, 생긴 해·없어진 해.
- 17판(2026-11-27): 시외버스 1963–1990, 20개 노선.
- 18판(2026-11-27): 시외버스 터미널·정류장 11곳과 나가던 방면.
- 2026-11-27: 저장소 작업 브랜치 `metropolitan-layer-map`으로 옮김(`068f2f1`).
