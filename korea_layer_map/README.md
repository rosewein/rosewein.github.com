# 전국 연대지도(작업 이름)

「서울 도시 연대지도」(`seoul-layer-map/`)와 「수도권 도시 연대지도」(`metropolitan-layer-map` 브랜치)에 이어, 지도를 전국 범위로 넓히는 이지의 개인 연구다. 철도망과 고속도로가 언제 어떻게 뻗어 나갔는지, 공단·택지 같은 지역개발이 어떤 순서로 들어섰는지를 시대순으로 보려 한다. 지도 이름은 아직 정하지 않았다.

2026-11-27 현재는 자료를 만드는 단계다. 지도 화면(`index.html`)은 아직 없다. 지금 상태와 다음 할 일은 `HANDOFF.md`에 있다.

## 폴더 구성

| 자리 | 담는 것 |
|---|---|
| `HANDOFF.md` | 지금 상태, 다음 할 일, 원자료 자리, 새 작업 공간에서 시작하는 법, 스크립트 돌리는 순서 |
| `docs/자료후보.md` | 이지가 정한 범위, 받아 둔 전국 자료, 철도·지역개발 자료 후보, 비슷한 작업 |
| `docs/도로.md` | 고속도로: 한국도로공사 CSV, 재정 구간표, 재정 선형, 민자 개통일, 전국 선형, 단순 선형, 표준노드링크 판별 비교 |
| `docs/철도.md` | 철도: 국토교통부 한글 파일, 국철·도시철도 구간 사건표, 선형 잇기 계획 |
| `docs/checks/` | 고속도로 검사 그림(연말 상태, 단순화 비교) |
| `data/road/` | 고속도로 표와 선형(아래 「자료 파일」) |
| `data/rail/` | 철도 구간 사건표 |
| `src/paths.py` | 경로 한곳 모음. 원자료는 `KLM_RAW`, 큰 중간 파일은 `KLM_WORK` 환경변수로 준다 |
| `src/road/` | 고속도로 표·선형 스크립트 |
| `src/nodelink/` | 표준노드링크 판별 비교 스크립트와 시안 페이지(`site/`) |
| `src/rail/` | 철도 표 스크립트, OSM 철도 추출, 국토부 한글 파일 여는 도구 |

원자료(OSM pbf, 표준노드링크 zip 등)와 큰 중간 파일은 넣지 않았다. 자리와 받는 법은 `HANDOFF.md`에 있다.

## 자료 파일

| 파일 | 내용 |
|---|---|
| `data/road/재정고속도로_구간표_20261127.csv` | 한국도로공사 재정 고속국도 구간별 개통일 131행(신설 122, 선형 이설 7, 해제 2). `src/road/make_table.py`가 만든다 |
| `data/road/민자고속도로_개통일_20261127.csv` | 민자 고속도로 24번의 개통. 손으로 고쳐 온 표라 만드는 스크립트가 없다 |
| `data/road/전국고속도로_선형_20261127.zip` | 재정+민자 OSM 선(20,686개)에 `route_date`·`geom_date`를 붙인 GeoJSON(풀면 10.5MB) |
| `data/road/전국고속도로_단순_20261127.geojson` | 위 선을 노선마다 한 줄로 줄인 것(325개, 230KB). `src/road/simplify2.py`가 만든다 |
| `data/rail/국철_구간사건표_20261127.csv` | 국철(광역철도 포함) 구간별 개통·이설·복선·전철화·폐지 340행, 1899–2025 |
| `data/rail/도시철도_구간사건표_20261127.csv` | 도시철도 구간별 개통 79행, 1974–2025 |

표의 「확인 정도」 칸: 원문(파일이나 원문을 직접 열어 확인), 변환(변환된 페이지·위키백과 등), 요약(검색 결과 요약), 추정.
